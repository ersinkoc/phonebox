Pages

Each page is a 12 × 6 grid of widgets. Pick a page on the left, arrange its widgets on the phone below and set their options. Drag pages to reorder them; the first one is the home page the panel returns to when idle. On the phone, swipe, use the volume keys, or tap a dot to go to its page (or slide along the dots to pick one); tap the current dot or the grid button next to the dots, or long-press an empty part of a page, for an overview of all pages.

Shortcuts

The keys shown by Shortcut grid and Big button widgets. Click a key to edit it, drag to reorder. The phone only sends the key's id; commands never leave this computer.

Rules

Let the panel react to what happens on this computer: show the AI page when Claude needs you, the music page when something plays, an "on air" sign during calls. A rule fires when its condition starts; with only while it lasts the phone goes back to where it was (and a pushed value is removed) when the condition ends.

Page switches count down on the phone and wait while you use it (General › Page switching).

General

Weather, night mode, display behaviour and the phone connection.

Weather

Apps and models disagree by a degree or two. Only Automatic and GFS supply every value: with another model the UV index, and with some also the chance of rain, may be missing.

The phone asks Open-Meteo for this location only while a page has a widget that uses the weather (weather, forecast, sun & moon, a clock with its weather line, Custom HTML).

Ping

None ticked = automatic (the connected Ethernet and Wi-Fi adapters). With a VPN that carries the same traffic, or a reading that looks too high, tick only the adapter you use.

Calendars

For the Agenda widget and calendar rules. Paste an iCalendar (ICS) address: Google Calendar › Settings › your calendar › Secret address in iCal format; Outlook › Settings › Calendar › Shared calendars › Publish a calendar (ICS link); iCloud › share as a public calendar (webcal:// works). The addresses stay on this computer.

Photo frame

For the Photo frame widget: a folder of photos on this computer. A synced OneDrive, Dropbox or iCloud folder works too; photos that are only in the cloud are skipped. Large photos are scaled down here before they go to the phone, and the path stays on this computer.

PhoneBox reads the album from your Immich server and shows the preview-size pictures Immich makes. A read-only API key is enough: it needs the album.read, asset.read and asset.view permissions (Immich › Account Settings › API Keys). The address and key stay on this computer; only this server is contacted.

News feeds

RSS or Atom feeds for the News feeds widget. This computer fetches each one at most every 15 minutes, only while a page shows a News feeds widget; the addresses stay here.

Cameras

IP cameras for the Camera widget: a name and the camera’s RTSP address (rtsp://user:password@address:554/…, from its manual or app). This computer pulls a camera with ffmpeg only while a Camera widget shows it, and sends the phone a few pictures a second (set next to each camera). The addresses stay on this computer, but while a camera runs they are visible in its process list.

App console

Keys and a dial for the App console widget, per app: the widget shows the keys of the app in front on this computer and sends them only to that app. Apps are process names, as in Task Manager's Details tab (photoshop, gimp-2.10). One key per line, a label then the keys: Undo = ctrl+z. Windows only; the keys stay on this computer.

Home Assistant

For the Home Assistant widget. Create a token in Home Assistant › your profile › Security › Long-lived access tokens. The token stays on this computer; the phone only sees the entities its widgets list. (Home Assistant can also push values and notifications to the panel, see Webhooks.)

Discord

Connect to the Discord app on this PC (for the Discord widget)

Create an application at discord.com/developers/applications, add the redirect http://127.0.0.1 under OAuth2, and copy its client ID and secret here. Discord asks you to approve PhoneBox once. If it refuses the login, add your account under the application's App Testers. Step by step: docs/DISCORD.md.

Let shortcuts and custom widgets control Discord, without a Discord widget

For the agent's /api/discord actions: mute, deafen, input mode, leave and join. Off: they work only while a Discord widget with Control on is on an enabled page. On: they work without one. Either way, anything that can call the agent can use them, not only the widget: the paired phone (USB or Wi-Fi) and programs on this computer.

Start and stop Discord screen shares from the phone

Asks Discord for permission to start screen shares, so Discord asks you to approve PhoneBox once more. While the share view is open on the phone, PhoneBox lists the apps with a window on this computer (names only). Discord decides what it can share directly; for anything else use its picker on the computer. Also needs a Discord widget with Control on.

Show Discord chat and new-message dots on the phone (read-only)

Sends the text of the channels you open in the widget to the phone. Asks Discord for permission to read messages, so Discord asks you to approve PhoneBox once more. The text stays in memory only (never in a file or the log) and is gone when Discord disconnects or this is turned off. If you decline, only the chat stays off.

Steam

Connect Steam (for the Steam friends widget)

Create a user Web API key at steamcommunity.com/dev/apikey and enter your SteamID64 or profile URL. Custom profile names are resolved when saved; only the SteamID64 is stored. Your profile's friend list must be visible to this API key for GetFriendList; make Game details public to show games. The key stays on this computer. Step by step: docs/STEAM.md.

OBS Studio

Connect to OBS (for the OBS widget, the On air widget and rules)

In OBS: Tools › WebSocket Server Settings › Enable WebSocket server; copy the password from Show Connect Info.

Phone mic

Use the phone's microphone as a computer microphone

The phone's mic plays into a virtual cable such as VB-CABLE; apps pick the cable's other end (CABLE Output) as their microphone. Set up checks for the cable, downloads scrcpy-server 5.0.1 from GitHub if it is missing, and turns the mic on. The phone must be on USB. More options: Advanced › JSON (phoneMic).

Start muted

Mute only silences the mic on this computer; while the phone mic is on, the phone keeps recording. Turn it off to stop recording.

Battery care

A phone that is plugged in all the time wears its battery out. PhoneBox can keep it between two levels by switching the phone's power on and off. Phones cannot stop charging by themselves without root, so the power is switched where it comes from: a smart plug in Home Assistant (the phone on its own charger), or two shortcuts, for example uhubctl for a USB hub with switchable ports. Without USB power the panel keeps running over Wi-Fi.

Wi-Fi & Tailscale

Let the phone connect without the USB cable

Pair a phone by plugging it in once over USB after turning this on (and restarting), or without a cable: Pair a phone over Wi-Fi shows a QR code to scan with the phone's camera. The phone then talks HTTPS to this PC, trusts only this PC's certificate and has to present a secret key. The phone and this PC must be on the same network — or both on Tailscale, which also works from another place or across separate Wi-Fi networks. Windows Firewall asks once — allow it (tick the network type Tailscale uses, too).

Updates

Install new releases automatically

Checks on GitHub every 6 hours. The phone app is installed over USB without a prompt on the phone; the agent replaces its own files and restarts.

Webhooks

Push data into the panel from scripts, CI jobs, Home Assistant, cron … Values show up in Pushed value widgets (key = the last part of the URL), notifications in a toast on the phone and in the Notifications widget. Values survive restarts.
